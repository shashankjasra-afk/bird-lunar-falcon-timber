Golden sets · four fixes

Make every row gradeable

Magenta · prose, not an answer

"Evaluate alternatives, explain trade-offs, request approval." Only a judge can grade that. Add the checkable part: which supplier, how many tonnes, what cost, escalate yes or no.

Magenta · contradicts the data

Rows 3 and 10: "no single supplier can meet Day 5". The dataset has Prime Steel: 100 t, 2-day lead, and row 2 expects it. Label against the data, or change the data for that row.

DealFlow · two right answers

G007: "Escalate (or Approve if threshold low)". A golden row has one answer. Fix the threshold, then the label.

DealFlow · not adversarial

G008's quarter-end discount is a gaming signal. Adversarial means input that attacks the agent: instructions hidden in a quote's notes field.

Also Magenta: four rows vary the same Project A delay, so they test one thing four times. Spread them across failure types.

Spec lines

Zero is a goal. Twenty tests can't prove it.

Agent Mend · box 14

Why 9 out of 10?

A circular yields 15–20 findings, so at most ~2 misses, few enough for the analyst to catch. A wrong extra flag costs minutes; a miss costs an audit finding.

Security Analyzer · box 14

"≤ 5% false fixes", with its own caveat

"With about 20 verified fixes, one error already equals 5%, so treat the figure as directional." The team flagged the limit itself.

Agent Mend box 13: target zero · test: catch at least 19 of 20 planted bad proofs
19/20 is 95%, not zero. And 0 misses in 20 still allows a true miss rate up to ≈ 3/20 = 15%
→ state the target as a rate, then grow the test set until it can show it

SoloBiz: thresholds of 95%, 98% and 90% with no reason and no cost of a miss. Those are still guesses, written down.
